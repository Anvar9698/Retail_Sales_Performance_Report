# 📊 Retail Sales Performance Report
<img width="1422" height="742" alt="image" src="https://github.com/user-attachments/assets/6a04a4a4-f4f0-4b75-aca5-4606d04a4529" />

A **Power BI Dashboard** designed to analyze and visualize retail sales performance.  
This project provides insights into product categories, city‑level sales, and monthly trends to support better business decision‑making.

---

## 📖 Overview
- Visualizes sales by **Category**, **City**, and **Time (Month/Day)**.
- Displays product‑level metrics: **Quantity**, **Total Sales**, and **Average Sales**.
- Helps identify top‑performing products and regions.
- Built with interactive charts and tables for easy exploration.

---

## 🛠️ Tools & Technologies
- **Power BI Desktop**
- **Data Modeling (DAX, Relationships)**
- **Excel / CSV Data Sources**

---

## 📂 Dashboard Highlights
- **Sales by Category** → Donut chart (Electronics, Home Appliances, Accessories, Clothing).
- **Sales by City** → Bar chart (New York, Houston, Los Angeles, Chicago).
- **Sales by Month & Day** → Line chart (trend analysis).
- **Product Table** → Quantity, Total Sale, Average Sales.

---

## 🎯 Key Insights
- Electronics dominate sales (74% of total).
- New York leads in city‑level sales.
- Seasonal fluctuations observed between November and December.
- Product breakdown shows laptops and smartphones as major contributors.
